# Filtram — ads allowlist
#
# Эти домены НИКОГДА не должны попадать в финальный ads.txt даже если
# upstream-источник их туда включил. Строка = один полный домен (exact match).
# Wildcard-правила записываются как субдомен — при subtract'е генератор
# удалит и сам домен и все его поддомены (см. Filtram generator workflow).
#
# Формат:
#   domain.example              — один домен (точное совпадение)
#   .example.com                — wildcard "всё что заканчивается на .example.com"
#   # комментарий
#
# Сортировка не требуется — генератор сам сортирует.
#
# Как репортить false-positive:
#   1. Зайти на filtram.net / открыть Issue в Filtram-lists на GitHub
#   2. Указать блокируемый домен + куда он ведёт (реальный сервис)
#   3. Maintainer добавит в нужный allowlist
#
# ─────────────────────────────────────────────────────────────────────────
